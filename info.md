# JVC Projector Remote

Remote keys, input and picture settings, and diagnostic sensors for JVC D-ILA projectors. Includes native lens tap/hold controls and copy-paste dashboard templates.

The library is bundled: copy the complete `custom_components/jvc_projector` folder, including `_vendor`, and restart Home Assistant. Existing JVC config entries are reused. See the README for installation, migration, and dashboard setup.
